# TRD - Documento Técnico
## 1. Stack
- Backend: FastAPI (Python 3.12).
- DB: PostgreSQL 15 (Neon en producción).
- Frontend: Vanilla JS (en migración a React).
- CI/CD: GitHub Actions.
## 2. Arquitectura
- API RESTful con separación de capas (API -> Servicios -> Modelos).
- Autenticación con JWT.
- Validación estricta con Pydantic.
## 3. Infraestructura
- Backend: Render (plan gratuito).
- Frontend: Vercel (plan gratuito).
- DB: Neon (plan gratuito).
