# App Flow - Navegación
## 1. Login / Registro
- El usuario ingresa email y contraseña.
- Puede registrarse como paciente (nuevo).
## 2. Panel Paciente
- Inicio: Ver próximas citas.
- Reservar: Elegir especialidad -> médico -> fecha -> horario.
- Mis Citas: Cancelar o reprogramar.
## 3. Panel Admin
- Dashboard: Resumen del día.
- Citas: Listado general.
- Agenda: Vista semanal.
- Médicos: CRUD.
- Pacientes: CRUD.
- Ausencias: Gestión de faltas de médicos.
